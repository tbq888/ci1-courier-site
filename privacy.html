CI1 Courier — Privacy Policy

Last updated: 2026-10-30

Who uses it

CI1 Courier is used only by its developer, with the developer's own Google account. It is not offered to anyone else.

What Google data it accesses

  • Google Drive, read-only (drive.readonly): file names, timestamps, sizes, checksums and the text content of files inside a few of the developer's own Drive folders.
  • Files created by this app (drive.file): only files that this app itself creates. File creation is currently switched off.

How the data is used

The app processes Google Drive data on the developer's own computer and sends selected notification excerpts to the developer's own devices through a self-hosted Bark server and Apple's push notification service. These services may process notification data for delivery. Local mirrors and logs may also be synchronized through the developer's configured storage service.

Sharing

Google user data is not sold, not used for advertising, and not used to train AI or machine-learning models. CI1 Courier's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Local logs and state stay on the developer's computer and can be deleted at any time. Access can be revoked at myaccount.google.com/permissions.

Contact

Contact the developer via https://github.com/tbq888.
